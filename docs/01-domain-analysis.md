# 01. Domain Analysis
# Таҳлили соҳаи предметӣ

## 1. Муқаддима

Соҳаи предметии лоиҳаи «Коркарди веблоиҳаи идоракунии хобгоҳи донишҷӯён» раванди ташкил, идоракунӣ ва назорати фаъолияти хобгоҳи донишҷӯёнро дар бар мегирад.

Хобгоҳи донишҷӯён барои таъмин намудани донишҷӯён бо ҷойи истиқомат пешбинӣ шудааст.

## 2. Мушкилоти мавҷуда

Мушкилоти асосии идоракунии анъанавии хобгоҳ:

- Бақайдгирии дастии донишҷӯён.
- Душвории назорати ҷойҳои холии ҳуҷраҳо.
- Мураккабии тақсимоти донишҷӯён.
- Назорати номукаммали пардохтҳо.
- Душвории ҷустуҷӯи маълумот.
- Таҳияи ҳисобот бо роҳи дастӣ.
- Эҳтимоли гум шудани ҳуҷҷатҳо.

## 3. Ҳалли пешниҳодшаванда

Барои бартараф намудани мушкилоти мазкур таҳияи системаи ягонаи вебӣ пешниҳод карда мешавад.

Система маълумоти донишҷӯён, ҳуҷраҳо, ҷойҳои истиқоматӣ, пардохтҳо ва аризаҳоро ба таври электронӣ идора мекунад.

## 4. Иштирокчиёни система (Actors)

### 4.1. Administrator

- Идоракунии пурраи система.
- Идоракунии истифодабарандагон.
- Идоракунии кормандон.
- Дидани ҳисобот ва омор.
- Назорати фаъолияти система.

### 4.2. Dormitory Manager

- Бақайдгирии донишҷӯён.
- Идоракунии ҳуҷраҳо.
- Ҷойгиркунии донишҷӯён.
- Баррасии аризаҳо.
- Назорати пардохтҳо.

### 4.3. Student

- Бақайдгирӣ ва воридшавӣ.
- Дидани маълумоти шахсӣ.
- Пешниҳоди ариза барои гирифтани ҷой.
- Дидани маълумоти ҳуҷраи истиқоматӣ.
- Дидани ҳолати пардохтҳо.

## 5. Объектҳои асосии соҳаи предметӣ

| Объект | Тавсиф |
|---|---|
| Student | Маълумоти донишҷӯ |
| Room | Маълумоти ҳуҷра |
| Building | Бинои хобгоҳ |
| Application | Аризаи донишҷӯ |
| Allocation | Тақсимоти ҷой |
| Payment | Пардохтҳо |
| User | Истифодабарандаи система |
| Staff | Кормандони хобгоҳ |

## 6. Равандҳои асосии бизнесӣ

1. Бақайдгирии донишҷӯ.
2. Пешниҳоди ариза барои ҷойгиршавӣ.
3. Баррасии ариза аз ҷониби мудири хобгоҳ.
4. Санҷиши ҷойҳои холӣ.
5. Ҷойгиркунии донишҷӯ дар ҳуҷра.
6. Бақайдгирии пардохт.
7. Назорати истиқомати донишҷӯ.
8. Таҳияи ҳисобот.

## 7. Натиҷаи таҳлил

Дар натиҷаи таҳлили соҳаи предметӣ муайян гардид, ки барои идоракунии самараноки хобгоҳи донишҷӯён системаи ягонаи вебӣ зарур мебошад.

Система бояд равандҳои бақайдгирӣ, идоракунии ҳуҷраҳо, тақсимоти ҷойҳо, назорати пардохтҳо ва таҳияи ҳисоботро автоматӣ намояд.
