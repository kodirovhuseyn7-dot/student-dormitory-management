# 02. Сравнительная матрица аналогов

## 1. Мақсади муқоиса

Мақсади муқоиса омӯзиши усулҳои мавҷудаи идоракунии хобгоҳ ва муайян намудани бартариҳои системаи пешниҳодшавандаи Student Dormitory Management System мебошад.

## 2. Системаҳо ва усулҳои муқоисашаванда

Барои муқоиса се усул интихоб карда шудаанд:

1. Усули анъанавӣ — идоракунӣ тавассути ҳуҷҷатҳои коғазӣ.
2. Усули электронӣ — истифодаи Microsoft Excel.
3. SDMS — веб-системаи пешниҳодшаванда.

## 3. Матритсаи муқоиса

| Меъёри муқоиса | Коғазӣ | Excel | SDMS |
|---|---|---|---|
| Бақайдгирии донишҷӯён | Дастӣ | Электронӣ | Автоматӣ |
| Идоракунии ҳуҷраҳо | Дастӣ | Қисман | Пурра |
| Назорати ҷойҳои холӣ | Душвор | Қисман | Автоматӣ |
| Ҷойгиркунии донишҷӯён | Дастӣ | Қисман | Идорашаванда |
| Назорати пардохтҳо | Дастӣ | Қисман | Электронӣ |
| Ҷустуҷӯи маълумот | Суст | Миёна | Зуд |
| Ҳисобот | Дастӣ | Қисман | Автоматӣ |
| Дастрасии онлайн | Не | Маҳдуд | Ҳа |
| Идоракунии корбарон | Не | Маҳдуд | Ҳа |
| Амнияти маълумот | Паст | Миёна | Назоратшаванда |

## 4. Таҳлили натиҷаҳои муқоиса

### 4.1. Усули анъанавӣ

Бартариҳо:
- Соддагии истифода.
- Зарурати таҷҳизоти махсус надорад.

Камбудиҳо:
- Вақти зиёд талаб мекунад.
- Эҳтимоли гум шудани ҳуҷҷатҳо вуҷуд дорад.
- Ҷустуҷӯи маълумот душвор аст.

### 4.2. Истифодаи Microsoft Excel

Бартариҳо:
- Нигоҳдории электронии маълумот.
- Имконияти ҳисобкунӣ ва филтркунӣ.
- Соддагии истифода.

Камбудиҳо:
- Идоракунии пурраи равандҳои хобгоҳро таъмин намекунад.
- Имкониятҳои маҳдуди идоракунии истифодабарандагон.
- Мураккабии ҳамзамон кор кардани якчанд истифодабаранда.

### 4.3. Student Dormitory Management System

Бартариҳо:
- Автоматизатсияи равандҳои асосӣ.
- Идоракунии марказонидашудаи маълумот.
- Назорати ҷойҳои холӣ.
- Идоракунии донишҷӯён ва ҳуҷраҳо.
- Назорати пардохтҳо.
- Таҳияи ҳисобот.
- Дастрасӣ тавассути браузер.

## 5. Хулоса

Дар натиҷаи муқоиса муайян гардид, ки усулҳои анъанавӣ ва истифодаи ҷадвалҳои Excel барои идоракунии пурраи хобгоҳи донишҷӯён маҳдудият доранд.

Аз ин рӯ, таҳияи Student Dormitory Management System ҳамчун роҳи ҳалли масъала пешниҳод карда мешавад.

Система бояд идоракунии донишҷӯён, ҳуҷраҳо, тақсимоти ҷойҳо, пардохтҳо ва ҳисоботро дар муҳити ягона таъмин намояд.
