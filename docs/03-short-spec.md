# 03. Краткое техническое задание (Short Specification)

## 1. Номи лоиҳа

Коркарди веблоиҳаи идоракунии хобгоҳи донишҷӯён (Student Dormitory Management System — SDMS).

## 2. Асос барои таҳияи лоиҳа

Асоси таҳияи лоиҳа зарурати автоматизатсияи раванди идоракунии хобгоҳи донишҷӯён, бақайдгирии донишҷӯён, идоракунии ҳуҷраҳо ва назорати пардохтҳо мебошад.

## 3. Мақсади лоиҳа

Мақсади асосӣ таҳияи веб-системаи ягона барои автоматизатсияи фаъолияти маъмурияти хобгоҳ ва беҳтар намудани хизматрасонӣ ба донишҷӯён мебошад.

## 4. Вазифаҳои асосӣ

- Таҳияи интерфейси истифодабаранда.
- Ташкили бақайдгирӣ ва авторизатсия.
- Идоракунии маълумоти донишҷӯён.
- Идоракунии биноҳо ва ҳуҷраҳо.
- Назорати ҷойҳои холӣ.
- Тақсимоти донишҷӯён ба ҳуҷраҳо.
- Қабул ва баррасии аризаҳо.
- Идоракунии пардохтҳо.
- Таҳияи ҳисобот ва омор.

## 5. Иштирокчиёни система

### 5.1. Administrator

- Идоракунии истифодабарандагон.
- Идоракунии кормандон.
- Дастрасӣ ба ҳамаи модулҳои система.
- Дидани ҳисобот ва омор.
- Назорати умумии система.

### 5.2. Dormitory Manager

- Идоракунии донишҷӯён.
- Идоракунии ҳуҷраҳо.
- Ҷойгиркунии донишҷӯён.
- Баррасии аризаҳо.
- Назорати пардохтҳо.

### 5.3. Student

- Бақайдгирӣ ва воридшавӣ.
- Дидани маълумоти шахсӣ.
- Пешниҳоди ариза.
- Дидани маълумоти ҳуҷра.
- Санҷидани ҳолати пардохтҳо.

## 6. Талаботи функсионалӣ (Functional Requirements)

Система бояд имкониятҳои зеринро таъмин намояд:

**FR-01.** Бақайдгирӣ ва воридшавии истифодабарандагон.

**FR-02.** Идоракунии маълумоти донишҷӯён.

**FR-03.** Илова, таҳрир ва нест кардани маълумоти ҳуҷраҳо.

**FR-04.** Идоракунии биноҳои хобгоҳ.

**FR-05.** Назорати ҷойҳои холӣ дар ҳуҷраҳо.

**FR-06.** Тақсимоти донишҷӯён ба ҳуҷраҳо.

**FR-07.** Пешниҳод ва баррасии аризаҳо.

**FR-08.** Сабт ва назорати пардохтҳо.

**FR-09.** Ҷустуҷӯ ва филтркунии маълумот.

**FR-10.** Таҳияи ҳисобот ва омор.

## 7. Талаботи ғайрифунксионалӣ (Non-Functional Requirements)

- Амнияти маълумоти истифодабарандагон.
- Интерфейси фаҳмо ва қулай.
- Суръати хуби кори система.
- Мутобиқат бо браузерҳои муосир.
- Дурустии нигоҳдории маълумот.
- Имконияти васеъ кардани система.
- Назорати ҳуқуқи дастрасӣ.

## 8. Технологияҳои истифодашаванда

| Технология | Таъинот |
|---|---|
| Go (Golang) | Таҳияи Backend |
| HTML5 | Сохтори интерфейс |
| CSS3 | Ороиши интерфейс |
| JavaScript | Функсияҳои интерактивӣ |
| MySQL | Пойгоҳи додаҳо |
| Git | Назорати версияҳо |
| GitHub | Нигоҳдорӣ ва идоракунии лоиҳа |
| Postman | Санҷиши API |

## 9. Маҳдудиятҳои лоиҳа

- Система ҳамчун веб-барнома таҳия мешавад.
- Барои истифода браузер ва пайвастшавӣ ба сервер зарур аст.
- Дастрасӣ ба имкониятҳо вобаста ба нақши истифодабаранда мебошад.
- Маълумот дар пойгоҳи додаҳои MySQL нигоҳ дошта мешавад.

## 10. Натиҷаи интизоршаванда

Дар натиҷаи иҷрои лоиҳа веб-системаи коршоям барои идоракунии хобгоҳи донишҷӯён таҳия карда мешавад.

Система бояд имконияти идоракунии донишҷӯён, ҳуҷраҳо, тақсимоти ҷойҳо, аризаҳо ва пардохтҳоро таъмин намояд.
