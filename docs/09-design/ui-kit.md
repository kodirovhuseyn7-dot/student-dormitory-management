# UI Kit — Student Dormitory Management System

## 1. Маълумоти умумӣ
Ин UI Kit барои тарҳи интерфейси системаи идоракунии хобгоҳ омода шудааст.

## 2. Рангҳо

| Ном | Рамзи ранг | Истифода |
|---|---|---|
| Primary | `#198754` | Тугмаҳои асосӣ |
| Secondary | `#6C757D` | Тугмаҳои иловагӣ |
| Background | `#FFFFFF` | Заминаи асосӣ |
| Surface | `#F8F9FA` | Заминаи қисмҳо |
| Text | `#212529` | Матни асосӣ |
| Error | `#DC3545` | Хато ва радкунӣ |

## 3. Услубҳои матн

| Услуб | Андоза | Ғафсӣ |
|---|---:|---|
| Heading | 32 px | Bold |
| Title | 24 px | Bold |
| Body | 16 px | Regular |
| Caption | 14 px | Regular |

Шрифт: Inter. Матни кириллӣ истифода мешавад.

## 4. Тугмаҳо
- Primary — амали асосӣ.
- Secondary — амали иловагӣ.
- Danger — амали радкунӣ ё хатарнок.

## 5. Майдонҳои воридкунӣ
- Default — ҳолати оддӣ.
- Focus — ҳангоми фаъол будани майдон.
- Error — ҳангоми ворид кардани маълумоти нодуруст.

Майдонҳои Email ва Password Label доранд.

## 6. Корти ҳуҷра
Маълумоти рақами ҳуҷра, шумораи ҷойҳо, ҳолати ҳуҷра ва амали интихобро нишон медиҳад.

## 7. Экранҳо
1. Login
2. Dashboard
3. Rooms
4. Applications
5. Mobile
6. Confirm Overlay

## 8. Prototype
Дар прототип гузаришҳои байни Login, Dashboard, Rooms ва Applications сохта шудаанд. Барои тасдиқи ариза равзанаи Confirm Overlay истифода мешавад.

## 9. Accessibility
- Баландии тугмаи Sign in: 54 px.
- Баландии Input-и Email: 54 px.
- Баландии Input-и Password: 54 px.
- Андозаҳо аз ҳадди ақали 44 px зиёданд.
- Email ва Password дорои Label мебошанд.
- Контрасти матни `#212529` дар заминаи `#FFFFFF`: 15.42:1.
