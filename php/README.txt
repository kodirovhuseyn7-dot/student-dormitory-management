SDMS - Student Dormitory Management System

1. Нусхаи эҳтиётии лоиҳаи пешинаро нигоҳ доред.
2. ZIP-ро кушоед.
3. Ҳамаи файлҳо ва папкаҳои онро ба:
   C:\xampp\htdocs\student-dormitory-management\php\
   нусхабардорӣ кунед ва файлҳои мавҷударо Replace кунед.
4. Боварӣ ҳосил кунед, ки базаи student_dormitory ва 7 ҷадвали он мавҷуданд.
5. Дар db.php номи база, username ва password-и MySQL-ро санҷед.
   Пешфарз: localhost / student_dormitory / root / password empty.
6. Дар браузер кушоед:
   http://localhost/student-dormitory-management/php/
   ё /php/login.php

ЭЗОҲИ МУҲИМ:
- Лоиҳа schema-и мавҷудаи student_dormitory-ро истифода мебарад.
- Регистршавӣ ҳисоби student месозад.
- Барои Admin/Manager ҳисоби мавҷударо истифода баред ё нақши корбарро дар phpMyAdmin тағйир диҳед.
- Ин версия пардохтро ҳамчун сабти дохилӣ идора мекунад; пайвастшавӣ ба бонк вуҷуд надорад.
- Пеш аз иваз кардани файлҳо нусхаи эҳтиётӣ гиред.
